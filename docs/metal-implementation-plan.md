## Phase map and sequencing

```
P0 Baselines [done] ──► P2 Renderer boundary [landed, gate met 2026-08-21] ──► P3 GL on RenderFrame ──► P4 Metal foundation ──► P5 Targets & composition ──► P6 Materials ──► P7 Hardening
                            ▲
P1 Cocoa platform [done] ───┘  (P1 and P2 both landed 2026-08-20 — sequentially in the end, though neither blocked the other; P4 needs P1+P3 done)
```

- **P1 ∥ P2:** the Cocoa window needs no renderer work and the boundary needs no macOS.
- **P3 before P4** is the plan's central risk control: the frame model must reproduce today's GL output pixel-for-pixel *on the existing platforms* before any Metal code interprets it (companion doc, Phase 3 rationale).
- P5 and P6 have a partial overlap opportunity: built-in materials land in P4; the shader toolchain (P6) can start as soon as P2 freezes `MaterialParams` — **which it did on 2026-08-20 (`render/materialparams.h`, std140, `sizeof == 80`, offsets static_asserted), so P6 toolchain work is unblocked today**.

Scope calibration from the companion doc's table: this is the "Backend-neutral frame architecture plus OpenGL migration" (Large) plus "Direct Metal with full OpenGL visual parity" (Very large), with P1 "Medium" and P7 "Medium after rendering works". The existing Vulkan renderer (~5,800 lines) and the Win32/X11 windows (~1,100–1,300 lines each) remain the best available size anchors.

What remains here is only the GL-side mapping of the block onto the legacy uniform locations.** It is latent, not live — `u_ItemId` is never bound in shipped code — so there is no prior visual behavior to preserve; ~~the requirement is only that the Metal ABI must not inherit the shared index space.~~ **Closed 2026-08-20: it cannot inherit it, per the correction above.** **Partly delivered 2026-08-21 (`360c581`):** `GLBackend` uploads the block's *map group* onto the legacy slots (`MAP_ZOOM`, `MAP_WALKOFFSET`, `MAP_CENTER_COORD`, `MAP_GLOBAL_COORD`), which the map shader needs because the compiled path does not run the `onBeforeDraw` callback that used to set them.
